The discovery run recovered the official TALOS dataset page supplied by the human reviewer. It did not follow that page's explicit link to the most valuable public source, the Zenodo deposit. Its only displayed publication result, *Note su (-)αιθύσσω*, is a lexical collision and does not concern this ontology. A later manual search found the relevant 2025 paper *Creating ontoterminologies for antiquity: workflow, challenges and solutions*.

There are no pre-existing curated ALyrA sources to recover. No public source is being compared with an undiscoverable local derivative. The RDF deposit, description, and query examples are all public and should reasonably have been found.

## B. Prioritized review

### Likely sources of new SPARQL or competency questions

1. **Zenodo ALyrA v1.0 record — high priority.** The record description contains five authored natural-language question and SPARQL pairs, which the human reviewer has confirmed are valid. The downloadable RDF file is the complete published v1.0 export. None of the ALyrA namespace or graph IRIs occurs in the current 408-query corpus.
2. **TALOS ALyrA dataset page — high priority for provenance, secondary for query discovery.** It identifies the creators, project, version, and metrics, and explicitly directs readers to Zenodo for the competency questions and SPARQL.
3. **2025 ontoterminology workflow paper — medium priority.** Section 4, pages 6–7, gives one complete ALyrA `SELECT` and its result table. It asks for the essential differences defining “hymn” and the poetess who composed it. This overlaps Zenodo query #2 but is not textually equivalent: the paper returns defining `diffLabel` values and restricts the composer to `Archaic_Lyric_Poetess`, whereas Zenodo #2 returns the definition, all author names, and centuries of living. Treat it as one additional authored query variant, not a sixth independent topic.

### Queries for other ontoterminologies in the same paper

The paper is a mixed-KG source and must not be extracted wholesale under ALyrA. In addition to the ALyrA query, it contains:

- **Ancient Greek Oratory Ontology:** Section 4, page 6 queries the ancient Greek terms and natural-language definitions for legal proceedings supervised by the Thesmothetai. It uses graph `http://www.ontologia.fr/OTB/oratory_v.1.0.rdf`; the paper cites [Zenodo 13379144](https://doi.org/10.5281/zenodo.13379144).
- **Göbekli Tepe Ontoterminology:** Section 4, page 7 queries English terms and definitions for archaeological concepts. It uses graph `http://www.ontologia.fr/OTB/Gobekli_Tepe_v.1.0.rdf`; the paper cites [Zenodo 13370343](https://doi.org/10.5281/zenodo.13370343).

These are authored and potentially valuable, but they are discovery leads for their respective graphs rather than ALyrA queries. The full paper is retained for provenance with bulk extraction disabled; only its ALyrA query has a per-KG curated record.

### Provenance or schema context

- ALyrA v1.0 was created by Rafail Giannadakis under Maria Papadopoulou's supervision in the University of Crete's TALOS AI for SSH project.
- The examples use the ontology namespace `http://www.ontologia.fr/OTB/ALyrA_v.1.0#` and named graph `http://ontologia.fr/OTB/ALyrA_v.1.0.rdf`.
- The Zenodo record provides `ALyrA_v.1.0.rdf.rdf` plus an OTB file and HTML dictionaries. The duplicated `.rdf.rdf` suffix is the deposited filename, not a transcription error.
- Direct inspection of the 503,282-byte RDF/XML file found the complete schema and data together: 29 SKOS concepts, 38 explicit top-level OWL class elements, 20 explicit top-level object-property elements, 6 datatype properties, 101 explicit `owl:NamedIndividual` elements, 101 TEDI objects, 58 terms, and 247 proper names. The latter four counts exactly match the TALOS/Zenodo TEDI metrics. Protégé reports 610 individuals because TEDI terms, proper names, and related resources are also modelled as individuals, not only those serialized with the `owl:NamedIndividual` element name.

### Duplicates, synthetic material, obsolete sources, or wrong ontologies

- The five Zenodo examples and the closely related paper variant are authored for ALyrA, not synthetic tests or application-internal probes.
- No exact or graph-level overlap was found in the current extracted corpus.
- The generic `https://sparql.org/sparql.html` link is a browser-based SPARQL client, not an ALyrA service. It must not be recorded as this graph's endpoint.
- The unrelated publication result should be rejected.
- No public GitHub, GitLab, project-hosted source repository, or repository link in the authoritative TALOS and Zenodo records was found. Search results for the exact ontology name, namespace, creator, and aliases led back to TALOS, Zenodo, and publications rather than a code repository.

### Inaccessible or unresolved candidates

- No dedicated public ALyrA endpoint was located. The examples name a graph IRI, but that does not establish a live service.
- The record is licensed CC BY-NC-ND 4.0. Whether and how its query text may be incorporated into the project requires human licensing judgment.

## D. Assessment

The discovery run was useful mainly because it confirmed the official identity page. Its recall was otherwise weak: it missed the query-bearing Zenodo record even though the recovered page directly advertises it, and it produced an irrelevant publication. This is a direct link-traversal failure, not merely a ranking failure: authoritative pages must be followed to their linked deposits and files. Manual follow-up established a small but strong source set: one authoritative documentation page, one complete versioned data export, five validated Zenodo query/CQ pairs, and one closely overlapping authored query variant in a 2025 paper. No repository was found.

Human judgment is required on licensing, the absence of a live endpoint, and whether the questions are sufficiently well specified for benchmark use. The approved ALyrA sources and local-dump seed have now been catalogued, including a curated record containing only the paper's ALyrA query. Query extraction remains paused while the other new graphs are reviewed.
