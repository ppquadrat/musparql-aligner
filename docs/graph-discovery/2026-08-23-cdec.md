## B. Prioritized review

### Likely sources of new SPARQL or competency questions

1. **Official CDEC examples — highest priority.** The page contains nine complete, Italian-language `SELECT` examples about arrests and deportations, places, convoys, gender composition, children, selections on arrival, political opponents, and deaths. They are clearly authored examples, not tests.
2. **The Holocaust Archival Material Knowledge Graph paper — contextual candidate.** Page 10, Listing 1 contains a complete federated `SELECT` joining EHRI KG data to the CDEC endpoint to retrieve records about people deported to Auschwitz. It demonstrates genuine CDEC use but primarily concerns the EHRI graph, so it is not a canonical CDEC-only benchmark source.
3. **EHRI2LOD repository — exclude from normal query extraction.** `src/auxFiles/linksToCDEC/queryToMatchToCDEC.rq` is a federated `CONSTRUCT` used to link EHRI people to CDEC by label. It is an authored data-integration routine, not an end-user competency question.

### Provenance or schema context

- [CDEC's current overview](https://www.cdec.it/dati-cdec/) identifies the Linked Open Data service and documents the historical Shoah/Open Memory focus.
- The current endpoint `https://lod.xdams.org/sparql` returned SPARQL JSON for a minimal read-only query on 2026-08-23. Older documentation uses the HTTP form.
- The nine official examples target named graph `http://dati.cdec.it/lod/shoah/` and the older CDEC Shoah ontology namespaces.
- The [current Digital Library project page](https://digital-library.cdec.it/cdec-opac/il-progetto) says the 2025 edition extends LOD treatment across broader archival, photographic, and audiovisual holdings and uses FOAF, SKOS, Dublin Core, OAD, ARCO, and the Shoah ontology. This creates a material version/scope distinction.

### Duplicates, synthetic material, obsolete sources, or wrong ontologies

- No CDEC identifier or namespace occurs in the current extracted corpus, so the nine official examples are prospectively new.
- The EHRI paper and repository are not wrong, but the graph of primary interest there is EHRI. Their federated queries should be classified as cross-KG provenance/integration material, not presented as ordinary CDEC queries.
- Discovery publications about Jewish history, museums, photography, or organizations named CDEC do not become KG sources merely because they share the acronym or subject.
- The public examples may describe an older graph scope. “Official” does not guarantee current executability or suitability.

### Inaccessible or unresolved candidates

- The linked Shoah ontology reference document at `https://dati.cdec.it/lod/shoah/reference-document.html` currently enters a broken redirect and returns 404. It is not a usable source.
- A direct read-only `ASK` confirmed that `http://dati.cdec.it/lod/shoah/` remains an active named graph at the current endpoint. The graph IRI should not be treated as a webpage.

## D. Assessment

The run usefully recovered the authoritative CDEC overview but missed the adjacent official query examples and returned many low-value topical results. The strongest prospective material is the nine-query official page. The main risk is currency: those examples explicitly target the historical Shoah graph, while the current Digital Library describes a wider 2025 graph ecosystem.

The approved catalog consists of the official nine-query examples page and the current xDams endpoint, with `http://dati.cdec.it/lod/shoah/` configured as its named graph. The broken ontology-documentation URL, general context pages, and cross-KG EHRI material were not added. Query extraction and execution have not been run; semantic suitability, Italian-to-English translation, and per-query currency still require review.
