            <h1 class="default">
                
                Public SPARQL Endpoint
            </h1>
        


    




    <p>On this page you can explore and query the <a href="https://nfdi4culture.de/services/details/culture-knowledge-graph.html" target="_blank" class="external-link">Culture Knowledge Graph</a> through a public SPARQL interface. For a quick start you can try out some of our prepared queries&nbsp;— for example list all <a href="https://nfdi4culture.de/go/sparql-repositories-ta4" target="_blank" rel="noopener noreferrer nofollow" title="https://nfdi4culture.de/go/sparql-repositories-ta4" class="external-link">research data repositories</a>&nbsp;or <a href="https://nfdi4culture.de/go/sparql-data-portals" target="_blank" title="https://nfdi4culture.de/go/sparql-data-portals" class="external-link">research data portals</a> described in the Knowledge Graph or get all <a href="https://nfdi4culture.de/go/sparql-partner-wikidata-mappings" target="_blank" rel="noopener noreferrer nofollow" title="https://nfdi4culture.de/go/sparql-partner-wikidata-mappings" class="external-link">partners of NFDI4Culture</a> with their different roles and mappings to Wikidata. You can also explore the dataset with the following queries:</p>
<p><a href="https://nfdi4culture.de/go/sparql-triple-count" target="_blank" class="button button-full-green" title="Count all triples">Count triples</a> <a href="https://nfdi4culture.de/go/sparql-show-types" target="_blank" class="button button-full-green" title="Show all types used">Show all types</a> <a href="https://nfdi4culture.de/go/sparql-count-instances-per-type" target="_blank" class="button button-full-green" title="Count the instances for each used type">Count instances per type</a> <a href="https://nfdi4culture.de/go/sparql-properties-per-type" target="_blank" class="button button-full-green" title="Show used properties for each type">Show properties for types</a></p>
